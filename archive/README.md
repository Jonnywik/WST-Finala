# Archived designs

The final application is **Night Shift** at the repository root, selected from the port 8003 preview.

These ZIP files preserve the other designs without adding extra runnable applications to the root:

| Snapshot | Design | Source commit |
|---|---|---|
| `claymorphism.zip` | Original, formerly port 8001 | `c7a65c0` |
| `teal-editorial.zip` | Teal editorial redesign, formerly port 8002 | `4eef96d` |
| `after-hours.zip` | Framed After Hours redesign, formerly port 8004 | `fda584d` |

Each contains the complete tracked source for that version, including its setup instructions and bundled assets. Extract into a separate folder to inspect an older design. These are source snapshots, not backups of the live database. They retain their original database defaults; running their installer can reset the shared database.
